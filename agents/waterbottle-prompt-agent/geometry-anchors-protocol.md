# Geometry Anchors Protocol

The Product Geometry Brief is not useful unless its concrete ratios are copied into every final prompt.

## Rule

Every main-image and detail-image prompt must include a `Geometry anchors` field before `Proportion lock`.

Do not write only:

```text
preserve proportions
```

Instead, copy the actual anchors:

```text
Geometry anchors: visual estimate from source image; overall product height:max width approx 3.2:1 including handle, bottle body height approx 68% of total, lid/handle assembly approx 32% of total, product occupies 80-84% of square canvas height, lid band width slightly wider than transparent body, handle state S1 folded/down.
```

## Anchor Checklist

Include as many as available:

- geometry source: confirmed dimensions or visual estimate;
- total height : maximum width;
- product canvas occupancy;
- transparent body : total height;
- lid/cap/handle assembly : total height;
- lid band width : body width;
- handle height/state;
- transparent top cap size;
- oval button position;
- straw position and angle;
- printed text position;
- bottom groove position;
- non-editable ratios.

If a value is unavailable, mark it `unknown / 待确认`.
