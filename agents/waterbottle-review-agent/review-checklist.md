# Water Bottle Review Checklist

Use this checklist when comparing source photos to generated e-commerce images.

## Hard Fail

- Product shape changed.
- Lid changed.
- Handle changed.
- Drinking spout or mouthpiece changed.
- Straw changed.
- Body grooves, scale marks, or printed text changed.
- Multiple product states were fused into one impossible object.
- SKU colors became different product designs.
- Functional parts were invented.
- Platform-risk elements were added.

## Must Compare

- silhouette;
- height/width ratio;
- body thickness;
- lid band height and width;
- button position and shape;
- cap shape and transparency;
- handle arc and attachment;
- straw position and angle;
- print content and placement;
- bottom molded grooves;
- SKU baseline and scale;
- scene props and occlusion;
- platform compliance.

## Required Output

- PASS / REVISE / FAIL
- scorecard
- source facts
- generated facts
- difference table
- prompt defects
- corrective prompt delta
